# Accessibility reviews

## Active standard

**Israeli Standard ת"י 5568** — legally aligned with **WCAG 2.1 Level AA** for public-facing web content in Israel.

All UI work in `client/` must follow this standard. Agents and contributors should read:

- [.cursor/rules/israeli-accessibility-is5568.mdc](../../.cursor/rules/israeli-accessibility-is5568.mdc) — Cursor rule (auto-applied for `client/**` edits)
- [is-5568-wcag-aa-pass-may-2026.md](is-5568-wcag-aa-pass-may-2026.md) — May 2026 implementation review (open items)

## Statement page

Production site must expose `/accessibility` (נגישות) with coordinator details and a way to report issues.
